## 为什么做 WorkAvatar

在日常办公中，我们积累了大量的本地文档——项目资料、合同报表、技术文档、会议记录……想让 AI 真正用好这些知识，目前常见的方案各有侧重：

- **纯关键词检索**：上手快，但只能做字面匹配，遇到概念理解、跨文档汇总的场景就力不从心
- **RAG 语义检索**：能理解语义，但通常需要先做全量向量化，文档越多等待越久；而且纯语义匹配偶尔会返回"看着相关、实际不对"的结果，精准度不够稳定
- **知识图谱**：能梳理复杂的关联关系，但构建和维护成本较高，前期投入大，适合特定领域的深度应用

我们在想，能不能找到一条中间道路：**先用最低的门槛快速用起来，然后在使用过程中逐步加深处理，让检索和总结能力越用越好**。

基于这个想法，WorkAvatar 采用了"轻量起步、渐进沉淀"的思路：

1. **零等待上手**：添加本地目录后，先构建轻量关键词索引，几分钟内就能开始搜索，不用等全量向量化
2. **用得越多越精准**：被频繁查阅的文档和主题，系统会自动补充深度处理——生成章节摘要、语义向量、知识卡片，检索质量逐步提升
3. **精确打底，语义加持**：关键词精确匹配保证结果的可靠性，语义相似查找扩展发现能力，两者结合尽量减少"漏检"和"误检"
4. **全程本地运行**：文档解析、索引构建、智能体推理都在本机完成，敏感数据不出本地

我们不追求一步到位构建完美的知识系统，而是希望它像一个好用的助手——一开始就能帮上忙，然后在相处中越来越懂你的资料。

## 核心能力

WorkAvatar 以**数字员工智能体**和**本地资料库（KMS）**为两大核心，其余办公功能（笔记、日历、语音、自动化）均以**插件**形式交付，可独立启停与二次开发。

### 数字员工智能体

<div align="center">
  <img src="images/智能体对话.png" alt="任务对话" width="49%" />
  <img src="images/数字员工.png" alt="数字员工管理" width="49%" />
</div>

创建你的数字员工，为每个角色配置专属的能力与档案——系统提示词、默认模型、可用工具、外部 MCP 服务、持久化记忆等。选择数字员工、输入需求即可开始任务，任务历史统一管理，随时回溯。

- **流式对话**：流式响应、思考过程与工具调用可视化；可同时向多个模型提问并排对比
- **工具系统**：内置文件读写、代码执行、联网搜索、资料库检索、Office 文档生成等工具，按"常驻 / 按需 / 关闭"三态配置，数字员工可自主决定调用方式
- **持久化记忆**：对话中的偏好与经验自动沉淀为记忆，下次任务按需注入
- **Skills 扩展**：支持社区 Skills 标准，可安装技能扩展数字员工能力
- **MCP 接入**：可连接外部 MCP 服务，扩展工具集
- **独立工作区**：每个任务拥有独立子目录，互不干扰；支持员工配置导入导出，方便团队复用

### 本地资料库（KMS）

<div align="center">
  <img src="images/资料库搜索.png" alt="资料库搜索" width="80%" />
</div>

把本地文档交给 AI 管理。添加目录后自动建立索引，支持 PDF、Word、Excel、PPT、图片（OCR）等常见格式，文件增删改自动同步。

- **关键词 + 语义混合检索**：精确匹配打底、语义查找扩展，兼顾精准与召回
- **AI 智能检索**：子智能体自主规划检索路径、多轮查找，输出结论与精准溯源
- **渐进式深度处理**：被频繁查阅的内容自动补充章节摘要、语义向量、知识卡片，越用越懂你的资料
- **资料合集**：手动挑选文件组成专题合集，自动生成全局摘要与目录结构

## 已开发插件

WorkAvatar 的导航页功能（笔记、日历、语音、自动化、数据模型）均以**插件**形式交付，独立打包为 `.wap`（WorkAvatar 插件包，内部为 zip 归档），用户可在「设置 → 插件」里导入、启停、删除与覆盖升级，也可直接双击 `.wap` 文件经确认后加载。所有插件统一走第三方插件逻辑，二次开发可独立于主程序进行。

### 笔记

<div align="center">
  <img src="images/笔记.png" alt="笔记" width="80%" />
</div>

基于 `.md` 文件存储的 Markdown 笔记，仓库可直接被外部工具与同步盘访问。

文件树 / 编辑器 / 大纲三栏布局，支持分屏预览、全文搜索、自动保存与外部文件同步。数字员工也可直接读写笔记。

### 日历与待办

<div align="center">
  <img src="images/日历.png" alt="日历与待办" width="80%" />
</div>

内置日程与 TODO 管理，数字员工可代为创建与修改，提醒自动触达。

月/周/日视图切换；日程支持彩色标签与重复规则；TODO 像写日记一样零负担记录，单行输入即可创建。应用内通知与系统通知自动切换，点击跳转日历页。支持 Outlook 单向同步。

### 语音识别

<div align="center">
  <img src="images/语音识别.png" alt="语音识别" width="80%" />
</div>

本地语音识别，录音转文字与会议纪要，全程离线，隐私安全。

支持多种识别模型；识别过程实时显示字幕，可悬浮窗投屏；录音结束后基于转录文本生成结构化会议纪要。

### 自动化

<div align="center">
  <img src="images/自动化任务.png" alt="自动化任务" width="80%" />
</div>

定时调度数字员工以固定提示词执行任务。配置首次运行时间与重复规则（每日/工作日/每周/每月等），支持失败重试与完成通知。

任务面板与执行历史双视角管理，点击历史记录可直接跳转对应对话。

### 数据模型

数据模型可视化编辑与 AI 建模。画布式编辑表、字段、外键关系，支持 DBML 导入导出与自动排版；选择数字员工对话，AI 即可帮你建表、加字段、建关系。

画布 + 检查器双视角编辑，主键/唯一/自增等约束可视化；右侧对话面板复用数字员工智能体，AI 编辑实时反映到画布。

## 插件化能力

WorkAvatar 的插件协议采用 **manifest 声明 + 双入口插件包 + 宿主扩展点** 的架构（VSCode 扩展简化版），并采用 **能力域授权**（capabilities）开放通用数据访问、统一执行入口、事件总线、UI 注入等放权能力，在相对安全前提下最大化第三方扩展性。

- 插件协议规范：[plugin-sdk/PROTOCOL.md](plugin-sdk/PROTOCOL.md)
- 插件 API 参考：[plugin-sdk/API_REFERENCE.md](plugin-sdk/API_REFERENCE.md)
- 插件能力矩阵：[plugin-sdk/CAPABILITY_MATRIX.md](plugin-sdk/CAPABILITY_MATRIX.md)
- 插件开发与打包教程（面向外部开发者）：[plugins/examples/hello-world/PLUGIN_DEVELOPMENT.md](plugins/examples/hello-world/PLUGIN_DEVELOPMENT.md)
- 插件示例工程：[plugins/examples/](plugins/examples/)

> **仓库结构**：内置插件源码（笔记/日历/语音/自动化/数据模型）独立为 git 子仓库 `WorkAvatar-Plugins`，作为本仓库 `plugins/` 的 submodule 依赖；`plugin-sdk/`（插件协议类型契约）由本仓库持有。克隆后需执行 `git submodule update --init --recursive` 拉取插件源码。

## 快速上手

### 第一步：添加资料目录

打开左侧导航的「资料库」，点击「添加目录」选择你想要索引的本地文件夹。系统会自动扫描目录下的文档，构建轻量索引。

支持的文档格式：PDF、Word（.doc/.docx）、Excel（.xls/.xlsx）、PPT（.ppt/.pptx）、Markdown、TXT、HTML、图片（OCR 识别）。

> 索引是增量的——文件增删改会自动同步，无需手动重建。

### 第二步：搜索你的资料

在资料库顶部的搜索框输入关键词：

- **普通搜索**：快速定位包含关键词的文件和段落，支持按文件类型、时间范围筛选
- **AI 搜索**：点击搜索框左侧切换到 AI 模式，输入问题后，系统会自主规划检索路径、多轮查找，最终输出整理后的结论和精准来源

搜索历史会保存在本地，点击搜索框的历史图标可查看。

### 第三步：组建资料合集

对于特定主题的资料，可以在「文档管理」中手动挑选文件组成「合集」。每个合集会自动生成全局摘要和目录结构，方便数字员工快速了解专题内容。

### 第四步：使用数字员工

切换到「数字员工」页面，选择或创建一个数字员工，就可以开始对话了。数字员工会自动调用本地资料库的检索能力，在回答中引用你的文档内容。

你也可以让数字员工帮你做更多事：

- 生成 Word、PPT、Excel 文档
- 执行代码、处理文件
- 联网搜索补充信息
- 调用社区 Skills 扩展能力

## 主要特点

| 特点 | 说明 |
|------|------|
| **轻量起步** | 关键词索引即可用，无需等待全量向量化 |
| **渐进精准** | 冷热知识自动沉淀，频繁查阅的内容深度处理，越用越好用 |
| **混合检索** | 精确匹配打底，语义查找扩展，结果更可靠 |
| **AI 检索闭环** | 子智能体自主规划多轮检索，输出结论+溯源，减少上下文冗余 |
| **全本地运行** | 文档解析、索引构建、智能体推理都在本机完成，数据不出本地 |
| **LLM 容错** | LLM 不可用时自动降级为基础检索，保证基本可用 |
| **增量更新** | 文件增删改自动同步索引，支持从指定节点增量重建 |
| **插件化扩展** | 导航页功能以插件交付，能力域授权，可独立启停与二次开发 |

## 适用场景

- **个人知识管理**：本地资料快速定位，AI 辅助梳理内容、总结要点
- **团队内部资料库**：私有化部署，支撑日常资料查询、业务分析
- **智能体开发**：为自定义 Agent 提供稳定的本地文档检索能力（MCP 接入）
- **敏感资料处理**：合同、报表、内部文档等不便上云的场景
- **专题研究**：用合集组织特定主题资料，渐进式深度加工

## 快速开始

### 环境要求

- Node.js >= 20.x
- npm >= 10.x
- Windows 10/11

### 安装依赖

```bash
# 拉取插件子仓库（内置插件源码）
git submodule update --init --recursive

npm install
```

### 开发模式启动

```bash
npm run dev
```

### 生产构建

```bash
npm run build
```
