## 为什么做 WorkAvatar

在日常办公中，我们积累了大量的本地文档——项目资料、合同报表、技术文档、会议记录……想让 AI 真正用好这些知识，目前常见的方案各有侧重：

- **纯关键词检索**：上手快，但只能做字面匹配，遇到概念理解、跨文档汇总的场景就力不从心
- **RAG 语义检索**：能理解语义，但通常需要先做全量向量化，文档越多等待越久；而且纯语义匹配偶尔会返回"看着相关、实际不对"的结果，精准度不够稳定
- **知识图谱**：能梳理复杂的关联关系，但构建和维护成本较高，前期投入大，适合特定领域的深度应用

我们在想，能不能找到一条中间道路：**先用最低的门槛快速用起来，然后在使用过程中逐步加深处理，让检索和总结能力越用越好**。

基于这个想法，WorkAvatar 采用了"轻量起步、渐进沉淀"的思路：

1. **零等待上手**：添加本地目录后，先构建轻量关键词索引，几分钟内就能开始搜索，不用等全量向量化
2. **用得越多越精准**：被频繁查阅的文档和主题，系统会自动补充深度处理——生成章节摘要、语义向量、知识卡片，检索质量逐步提升
3. **精确打底，语义加持**：关键词精确匹配保证结果的可靠性，语义相似查找扩展发现能力，两者结合尽量减少"漏检"和"误检"
4. **全程本地运行**：文档解析、索引构建、智能体推理都在本机完成，敏感数据不出本地

我们不追求一步到位构建完美的知识系统，而是希望它像一个好用的助手——一开始就能帮上忙，然后在相处中越来越懂你的资料。

## 快速上手

### 第一步：添加资料目录

打开左侧导航的「资料库」，点击「添加目录」选择你想要索引的本地文件夹。系统会自动扫描目录下的文档，构建轻量索引。

支持的文档格式：PDF、Word（.doc/.docx）、Excel（.xls/.xlsx）、PPT（.ppt/.pptx）、Markdown、TXT、HTML、图片（OCR 识别）。

> 索引是增量的——文件增删改会自动同步，无需手动重建。

### 第二步：搜索你的资料

在资料库顶部的搜索框输入关键词：

- **普通搜索**：快速定位包含关键词的文件和段落，支持按文件类型、时间范围筛选
- **AI 搜索**：点击搜索框左侧切换到 AI 模式，输入问题后，系统会自主规划检索路径、多轮查找，最终输出整理后的结论和精准来源

搜索历史会保存在本地，点击搜索框的历史图标可查看。

### 第三步：组建资料合集

对于特定主题的资料，可以在「文档管理」中手动挑选文件组成「合集」。每个合集会自动生成全局摘要和目录结构，方便数字员工快速了解专题内容。

### 第四步：使用数字员工

切换到「数字员工」页面，选择或创建一个数字员工，就可以开始对话了。数字员工会自动调用本地资料库的检索能力，在回答中引用你的文档内容。

你也可以让数字员工帮你做更多事：

- 生成 Word、PPT、Excel 文档
- 执行代码、处理文件
- 联网搜索补充信息
- 调用社区 Skills 扩展能力

## 核心功能

### 本地资料库

#### 混合检索引擎
- **关键词精确匹配**：基于 SQLite FTS5 全文索引，结果精准可追溯
- **语义相似查找**：支持向量检索，能找到语义相近但字面不同的内容
- **默认混合模式**：两种检索方式结合，兼顾精准度和召回率

#### AI 智能检索
- 内置独立检索子智能体，接到需求后自主判断问题类型（找信息、解释概念、梳理趋势、综合分析）
- 多轮检索闭环：规划路径 → 查找资料 → 补充验证 → 提炼结论
- 输出精炼结论 + 精准溯源（文件名、页码、段落），减少上下文冗余
- LLM 不可用时自动降级为基础检索，保证基本可用

#### 冷热知识渐进沉淀
- **轻量起步**：添加目录后先构建关键词索引，无需等待全量向量化
- **主动深度处理**：对合集或指定目录可一键启动深度处理，生成章节结构、段落摘要、文档摘要、合集摘要
- **知识卡片**：高频搜索的主题会自动生成知识卡片，提炼要点和引用来源，下次搜索直接呈现结构化结论
- **增量更新**：支持从指定节点开始重新生成，保留已有内容，避免重复计算

#### 文档管理
- 目录源自动索引 + 合集手动组织，两种方式管理资料
- 文档 → 章节 → 段落的层级浏览，保留原始结构
- 统计面板：索引状态、文件分布、存储占用一目了然
- 数据库清理：清理孤立索引、回收磁盘空间

### 数字员工

#### 智能对话
- 支持任意 OpenAI 兼容接口的 LLM 提供商
- 多模型对比：同时向多个模型提问，并排查看回答差异
- 分支对话：切换模型重新生成，保留原始回答

#### 跨任务记忆
- 自动提取用户偏好、决策结论、踩坑经验等持久化记忆
- 下次对话时按优先级注入上下文，用得越多越了解你
- 具备过时清理、精炼合并、重要性分级、容量控制等机制

#### 本地化工具链
- **Office 文档生成**：直接创建和编辑 Word、PPT、Excel
- **文件操作**：文件读写、目录管理，工作区外操作需用户确认
- **代码执行**：Node.js 沙箱环境，支持运行和调试代码
- **互联网搜索**：多搜索引擎支持，无需 API Key
- **Claude Skills**：支持安装社区技能，按需激活
- **独立工作区**：每个数字员工拥有独立工作目录，文件操作安全可控

### MCP 服务

WorkAvatar 的资料库检索能力可以通过 MCP（Model Context Protocol）服务暴露给其他智能体使用：

- 支持 Claude Code、Cursor 等兼容 MCP 协议的客户端
- 提供 9 个检索工具：列出数据源、统计信息、关键词搜索、AI 智能检索、获取内容、获取摘要、获取目录、获取段落、知识卡片
- 支持 Streamable HTTP 传输，兼容 2025-03-26 协议

### 日历与待办

内置日程与 TODO 管理，数字员工可代为创建与修改，提醒自动触达。

- **多视图日历**：月 / 周 / 日视图切换，日程色块 + TODO 优先级标记一目了然
- **日程管理**：标题、时间、全天事件、6 色标签、地点、描述；支持按天/工作日/周/月/年重复
- **TODO 管理**：截止时间、优先级、状态、标签、重复规则；按逾期/今日/本周/稍后/已完成分组展示
- **统计概览**：总数、待办、已完成、逾期、今日到期、完成率
- **智能提醒**：可配置提前提醒时间；应用前台时弹应用内通知，失焦或最小化时弹系统通知，点击跳转日历页
- **数字员工联动**：数字员工可代为创建/修改日程与 TODO，审批请求同样自动推送通知

### 自动化

定时调度数字员工以固定提示词执行任务，任务面板与执行历史双视角管理。

- **任务调度**：配置首次运行时间 + 重复规则（不重复/每日/工作日/每周/每月/每年）
- **执行配置**：选择数字员工、模型、提示词；支持高权限运行、失败重试、完成通知
- **任务面板**：状态徽标 + 下次/上次运行时间；支持立即执行、编辑、暂停/启用、删除
- **执行历史**：记录耗时、状态、触发方式与错误信息；点击「查看对话」直接跳转对应员工对话
- **对话同步**：删除执行历史会同步移除对应对话，反之亦然
- **异常恢复**：异常退出后自动清理残留运行状态

## 产品概览

### 主要特点

| 特点 | 说明 |
|------|------|
| **轻量起步** | 关键词索引即可用，无需等待全量向量化 |
| **渐进精准** | 冷热知识自动沉淀，频繁查阅的内容深度处理，越用越好用 |
| **混合检索** | 精确匹配打底，语义查找扩展，结果更可靠 |
| **AI 检索闭环** | 子智能体自主规划多轮检索，输出结论+溯源，减少上下文冗余 |
| **全本地运行** | 文档解析、索引构建、智能体推理都在本机完成，数据不出本地 |
| **LLM 容错** | LLM 不可用时自动降级为基础检索，保证基本可用 |
| **增量更新** | 文件增删改自动同步索引，支持从指定节点增量重建 |

### 适用场景

- **个人知识管理**：本地资料快速定位，AI 辅助梳理内容、总结要点
- **团队内部资料库**：私有化部署，支撑日常资料查询、业务分析
- **智能体开发**：为自定义 Agent 提供稳定的本地文档检索能力（MCP 接入）
- **敏感资料处理**：合同、报表、内部文档等不便上云的场景
- **专题研究**：用合集组织特定主题资料，渐进式深度加工

### 功能清单

- **多格式文档解析**：PDF、Word、Excel、PPT、图片（OCR）、Markdown、TXT、HTML
- **混合检索引擎**：FTS5 全文索引 + 向量语义检索 + 智能混合排序
- **AI 智能检索**：四阶段闭环检索子智能体（识别→规划→检索→提纯）
- **知识沉淀体系**：目录摘要、合集摘要、文件摘要、段落摘要、知识卡片
- **资料库管理**：目录源自动索引、合集手动管理、文档层级浏览、统计面板
- **数字员工系统**：自研 Agent 框架（ReAct / PlanExecute / ToolFilter）、工具调用、流式响应
- **跨任务记忆**：自动提取、过时清理、精炼合并、重要性分级
- **Office 文档生成**：Word、PPT、Excel 原生创建与编辑
- **多模型对比**：多提供商、多模型并排对比、分支对话
- **Skills**：社区技能安装与管理
- **员工导入导出**：配置 JSON 或完整包（.avatar），含 SHA-256 校验
- **语音输入**：本地语音识别，支持多种模型，可 GPU 加速
- **日历与待办**：多视图日历、日程/TODO 管理、智能提醒、数字员工可代为操作
- **自动化**：定时任务调度、重复规则、立即执行、执行历史、对话双向同步、失败重试与异常恢复

```bash
npm install
```

```bash
npm run dev
```

## 架构概览

项目采用 Electron 双进程架构：

- **主进程**：Node.js 环境，包含所有后端服务——数据库、文件解析、知识处理、搜索引擎、LLM 客户端、Agent 系统等
- **渲染进程**：React 前端，通过 IPC API 与主进程通信
- **共享层**：IPC 通道定义和类型，主进程与渲染进程共享
