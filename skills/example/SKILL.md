# 示例助手技能

这是一个示例技能，用于演示如何与数字员工进行交互。

## 功能说明

本技能展示了如何使用各种工具来帮助用户完成任务。

## 使用指南

1. 使用 `calculator` 工具进行数学计算
2. 使用 `date_time` 工具获取当前时间或进行日期计算
3. 使用 `string_utils` 工具处理字符串

助手: 使用 calculator 工具计算...

用户: "今天是星期几？"
助手: 使用 date_time 工具获取当前日期...
